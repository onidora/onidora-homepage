# GitHub Pages公開

## 目的と概要

完成したサイトをGitHub Pagesで公開し、GitHub Actionsで更新できるようにする。
依存は01のGitHub登録と02〜04のコンテンツ実装。このworkは将来の依頼用であり、今回の実装・設定対象外。

## 構成

```text
astro.config.mjs              修正: ローカル静的出力 → 確定したsite/base設定
.github/workflows/deploy.yml  新規: 承認されたブランチからの静的ビルド・公開
README.md                     修正: 未設定の説明 → 確認済み公開手順
```

## 完了条件

- owner、リポジトリ名、公開URLに応じたsite/baseが設定され、リポジトリ名変更にも追従できる。
- 権限を限定したGitHub ActionsでビルドとPages公開が成功し、公開URLで3ページと画像・リンクを確認できる。
- プロジェクト配下のbaseでも全リンクが動く。Nodeと依存バージョン、公開ブランチ、READMEの手順が一致する。
- ユーザーの公開許可を記録してから、公開設定変更とデプロイを行う。

## 方針と手順

1. 作業時点のAstro/GitHub公式ドキュメントとリポジトリの公開条件を確認する。
2. owner・リポジトリ名・ドメインを確定し、site/baseとActionsを設定する。
3. ローカルで型チェック・ビルド・base付きプレビューを検証し、READMEを更新する。
4. 変更内容・公開先を提示して公開許可を確認し、承認範囲でpush・Pages有効化・初回公開を行う。
5. 公開URLで表示とリンクを確認し、実施記録を残す。

## 着手条件（要確認）
