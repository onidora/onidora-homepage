# うらどらスタジオページ

## 目的と概要

18歳以上対象ブランドの入口として、全年齢で表示できる内容の `/uradora/` を追加する。
依存は [初期構築](archive/2026-10-27-01-初期構築とGitHub登録.md) のローカル基盤。[StudioActOneページ](2026-10-27-02-StudioActOneページ.md) が先に実装されていれば共通レイアウト・作品データ構造を利用する。
成人向け画像・動画・露骨な文章・公開設定は対象外。

## 構成

```text
src/pages/uradora/index.astro  新規: ブランド・作品紹介と外部リンク注意書き
src/data/site.ts              修正: UradoraSurvivors、Ci-enの任意URL
src/pages/index.astro         修正: 準備中 → 実装済みページへのリンク
public/images/               新規: 全年齢向けの仮ヘッダー
```

## 完了条件

- ブランド名、「18+」「18歳以上対象」、開発中のUradoraSurvivorsが明示される。
- 概要は「大量の敵を倒しながら成長するヴァンサバライクアクション。戦闘中に新たな従者を生み出し、仲間を増やして戦う独自のシステムを搭載。」を基にする。
- Ci-enは未設定時にリンクを出さない。設定後はリンク直近に成人向けコンテンツを含む注意書きが出る。
- 全年齢向けヘッダーだけを掲載し、両ブランドの作品が混在しない。
- トップと詳細の往復、キーボード、PC/狭幅表示、URL設定時と未設定時を確認し、check/buildが成功する。

## 方針と手順

1. 既存の作品データ・レイアウトを確認し、必要なブランドデータを追加する。
2. 見出しと外部リンクに対象年齢を明示し、仮ヘッダーを用いてページを実装する。
3. Ci-enの任意URLと未設定分岐を設け、トップの詳細リンクを有効化する。
4. 完了条件を検証する。Ci-enの正式URLと画像の提供は04へ引き継ぐ。
